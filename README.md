# ArenaConecta

![site preview](site_preview.png)

![Link do site em produção : https://poo-project.onrender.com](https://poo-project.onrender.com)
<br/>
O ArenaConecta é uma aplicação web desenvolvida para aproximar cidadãos, organizadores de eventos e administradores da Arena de Pernambuco. A plataforma centraliza a divulgação de eventos, facilita a descoberta de atividades culturais, esportivas e corporativas, e oferece ferramentas de gestão para a administração do espaço.

Por meio de visualização de eventos, sugestões da comunidade, agendamento de visitas e um dashboard com dados estatísticos de utilização da arena, o sistema busca aumentar o engajamento da população e otimizar o uso de um importante equipamento público, contribuindo para o desenvolvimento de uma cidade mais conectada e inteligente.

### 2. Apresentação do Projeto

#### 2.1 Título do Projeto
ArenaConecta

#### 2.2 Problema ou Necessidade Identificada

A Arena Pernambuco sofre com baixa ocupação efetiva e subutilização do seu espaço em relação ao seu enorme potencial para eventos esportivos, culturais e corporativos. O principal gargalo identificado é a dificuldade de comunicação e conexão entre as pessoas interessadas em participar de eventos e os organizadores ou administradores do espaço, o que prejudica a divulgação, a descoberta e a organização eficiente das atividades.

#### 2.3 Público-Alvo
- Cidadãos interessados em participar de eventos culturais, esportivos e corporativos
- Compradores de ingressos
- Administradores e gestores da Arena Pernambuco
- Clubes esportivos e federações esportivas
- Empresas parceiras e patrocinadores
- Comerciantes locais, como restaurantes, hotéis, estacionamentos e serviços de transporte próximos à arena

#### 2.4 Objetivo Geral do Projeto

Desenvolver uma aplicação web para a Arena Pernambuco, que conecte a população à programação da Arena Pernambuco, facilitando a divulgação das atividades, melhorando a comunicação entre o público e a administração, e incentivando a ocupação e o uso do equipamento público. Além de auxiliar na gestão dos eventos realizados e incentivar a ocupação e utilização do espaço público.

#### 2.5 Objetivos Específicos

| Nº | Objetivo específico |
|---|---|
| 1 | Desenvolver uma interface interativa para visualização dos próximos eventos agendados, permitindo filtros e ordenação por diferentes critérios. |
| 2 | Criar um painel de controle (dashboard) para os administradores com dados estatísticos e de uso do espaço (tendência central e dispersão). |
| 3 | Implementar um sistema de cadastro e gerenciamento de novos eventos exclusivo para os usuários administrativos. |
| 4 | Desenvolver um fluxo que permita aos usuários agendar visitas, confirmar participação ou realizar uma simulação de compra de ingressos. |
| 5 | Disponibilizar um canal onde os cidadãos possam enviar sugestões de novos eventos para a Arena. |

#### 2.6 Justificativa

Equipamentos públicos de grande porte como a Arena Pernambuco possuem alto custo de manutenção e precisam gerar valor social e econômico constante. Ao criar uma ponte digital entre a população e a administração do estádio, o projeto democratiza o acesso ao espaço público, fomenta a cultura e o esporte local, e fornece aos gestores as ferramentas necessárias para otimizar a infraestrutura existente de forma mais inteligente e orientada a dados.

### 3. Escopo do Projeto

#### 3.1 O que será entregue pelo projeto?

O projeto entregará uma aplicação web fullstack voltada para a divulgação e gerenciamento de eventos na Arena Pernambuco. A plataforma permitirá que usuários visualizem informações sobre eventos, datas, horários, localização e detalhes das programações disponíveis. Além disso, o sistema contará com uma área administrativa para gerenciamento dos eventos, possibilitando o cadastro, edição e remoção de informações pela administração ou organizadores responsáveis.

#### 3.2 O que não faz parte do projeto?

- Sistema próprio de pagamento e venda de ingressos
- Aplicativo mobile nativo para Android e iOS
- Integração com catracas físicas ou sistemas internos da Arena
- Funcionalidades de segurança e escalabilidade voltadas para grandes volumes de acesso

## Como Executar o Projeto

### Pré-requisitos
- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Execução com Docker

Para facilitar o provisionamento do ambiente, o projeto utiliza Docker e Docker Compose. Siga os passos abaixo:

1. Na raiz do projeto, execute o comando:
   ```bash
   docker-compose up --build
   ```

2. Após o build e a inicialização dos containers, a aplicação estará disponível em:
   `http://localhost:8080`

3. Para encerrar a execução:
   ```bash
   docker-compose down
   ```

### Persistência de Dados
O projeto utiliza um banco de dados H2. No Docker, os dados são persistidos em um volume chamado `app-data`, garantindo que as informações não sejam perdidas ao reiniciar os containers.
